# Clarity

## Objective
Help the user express ideas clearly and logically so listeners follow them effortlessly.

## Evaluate
- Sentence structure
- Unnecessary filler words
- Repetition
- Ambiguous language
- Logical flow
- Explanation quality

## Training Rules
- Prefer short sentences; one idea per sentence.
- State the main point first, then support it.
- Replace vague words ("things", "stuff") with specifics.
- Pause instead of using filler words.

## Practice Exercises
- Explain your daily routine in 30 seconds using exactly 5 sentences.
- Describe your current project using: problem, approach, result.
- Re-explain your last answer without any filler words.

## Scoring Criteria
- 90-100: Crisp, unambiguous, zero fillers, strong logical order.
- 70-89: Mostly clear; occasional filler or vague wording.
- 50-69: Understandable but repetitive or poorly ordered.
- Below 50: Hard to follow; ideas disconnected.

## Coaching Instructions
Point to SPECIFIC filler words or vague phrases the user used (quote them). Suggest the exact reworded sentence. Never invent content the user did not say.
